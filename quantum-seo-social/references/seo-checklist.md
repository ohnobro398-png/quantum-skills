# SEO Checklists

## Facebook post SEO (every post)

- [ ] Exact keyword in the first line
- [ ] Keyword repeated naturally 1 to 2 more times
- [ ] Price and delivery info present
- [ ] 5 to 8 hashtags: product keyword plus shop name plus broad tags
- [ ] Caption under 1,024 characters, no leading or trailing whitespace

## Web tool page SEO (every page)

- [ ] One target keyword in title tag, H1 and first paragraph
- [ ] Meta description under 160 characters promising the outcome
- [ ] FAQ section with schema markup for real user questions
- [ ] Images sized to display size with descriptive alt text
- [ ] Page loads fast on a mid range Android phone
- [ ] Bangla content where the audience reads Bangla

## Weekly SEO review

- [ ] Which keywords drove profile visits this week
- [ ] Top post by saves and shares, and why it won
- [ ] Any ranking change on Google targeted pages
- [ ] One keyword or format to double down on next week
- [ ] One loser to cut
